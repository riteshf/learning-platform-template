# Pre-Class: Prepare Your Lesson

Skim these steps to get ready to author content.

## Preparation

Before this session, ensure you can:
- Duplicate the lesson folder structure
- Edit MDX and JSON files
- Run `yarn validate` locally

<!-- question:db:Q_CC_001 -->

## Key concepts to review

- Lesson folder anatomy (`lesson.json`, phases, `slides/`, `questions.json`)
- MDX frontmatter and visibility
- MDX question markers and IDs

## Mini tasks

- Create a throwaway `my-sample-lesson/` folder locally
- Add one MDX slide and reference it in `lesson.json`
- Add one MCQ in `questions.json` and embed it in MDX
