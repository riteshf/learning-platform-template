# Pre-Class: Setup & Preparation

Use this page to prepare your content repo so the platform can ingest it.

## ✅ Minimum setup

- GitHub account (or Git provider) and git 2+
- Node 18+ (optional, for running local validator)
- Fork or copy this template into your own repository

<!-- question:db:Q_INTRO_001 -->

## 🔍 Quick verification commands

```bash
node --version
npm --version
git --version
yarn --version
``` 

Run the local validator (optional but recommended):

```bash
cd learning-platform-template
yarn install
yarn validate
```

## 📚 Optional pre-reading

- Content model: Git-based source of truth
- Three phases: Pre, Live, Post + Instructor Notes
- Questions model: MDX markers + questions.json definitions

## 📋 Ready-to-join checklist

- [ ] Tools installed and tested
- [ ] Created/duplicated a lesson folder skeleton
- [ ] Ran `yarn validate` and fixed any errors
- [ ] Questions captured for live Q&A

Next: head to the live class page.
