Follow this exact structure for each lesson. Replace `my-lesson/` with your slug.

```text
src/lessons/
   my-lesson/
      lesson.json
      pre.mdx
      live.mdx
      post.mdx
      instructor.mdx   # visibility: "instructor"
      slides/
         01-intro.mdx
         02-deep-dive.mdx
      assets/
         .keep
```

Minimal `lesson.json`:

```json
{
  "title": "My Lesson Title",
  "description": "What learners will do",
  "objectives": ["One", "Two"],
  "durationMinutes": 60,
  "tags": ["topic"],
  "slides": ["01-intro.mdx", "02-deep-dive.mdx"]
}
```

Embed questions inside MDX using comment markers:

```mdx
<!-- q:db:Q_MY_LESSON_001 -->  <!-- example (intentionally not valid) -->
```

Define all referenced question IDs in `src/lessons/my-lesson/questions.json`.
