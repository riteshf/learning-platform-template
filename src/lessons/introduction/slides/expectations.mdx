### 1) Create a slide file

- Add a new `.mdx` under `slides/` (e.g., `03-examples.mdx`)
- Include frontmatter:

```mdx
---
title: "Examples"
type: "content"
visibility: "public"
---
```

### 2) Reference it in `lesson.json`

Add the file name to the `slides` array so the platform can order slides:

```json
{
  "slides": ["01-intro.mdx", "02-deep-dive.mdx", "03-examples.mdx"]
}
```

### 3) Embed a question in your slide

Use a marker comment in MDX where the question should render:

```mdx
<!-- q:db:Q_EXAMPLES_001 -->  <!-- example (intentionally not valid) -->
```

Then define `Q_EXAMPLES_001` in `questions.json` with its type, options, and answer.

### 4) Instructor-only notes

Put teaching guidance in `instructor.mdx` (in the lesson folder root) and set `visibility: "instructor"` in the frontmatter. The platform will hide this from students.

---

You're ready to add questions next. See the examples in this lesson’s `questions.json`.
