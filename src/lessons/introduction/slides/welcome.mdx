# Welcome: How to Use the Platform

This guide shows instructors how to author content that the platform can ingest from Git.

You will:

- Create a lesson folder and `lesson.json`
- Add Pre, Live, Post, and Instructor Notes pages
- Create slides and reference them in `lesson.json`
- Embed questions using MDX markers
- Add all question definitions in `questions.json`

## Authoring Flow (High-Level)

- Author content in this repo format
- Run local validation to catch issues
- Link your GitHub repo in the platform UI
- Trigger a sync; the backend parses your repo and serves it live

> Tip: Keep file names stable; the platform relies on paths and IDs.
