# Create Files

Add these minimal files:

- `lesson.json` with `title`, `description`, `slides`
- `pre.mdx`, `live.mdx`, `post.mdx`
- `instructor.mdx` (visibility: instructor)

```json
{
  "title": "Sample Onboarding Lesson",
  "description": "A complete, create-from-scratch walkthrough",
  "slides": ["01-overview.mdx", "02-create-files.mdx", "03-questions.mdx"]
}
```
